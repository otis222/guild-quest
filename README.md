# 公會委託單

把基礎課作業拆成 10 分鐘的「公會委託」，每完成一關，就點亮自己 OC 設定卡的一片。

- **網址**：https://otis222.github.io/guild-quest/
- **目前上線**：v0.1。建立 OC、3D 公會大廳可以玩；委託迴圈（規格書第 3～7 項）在 v1.0 補上。

這是 TAICA「生成式 AI：文字與圖像生成的原理與實務」第五週作業〈用 Vibe Coding 做出一個互動網頁〉。
作品延伸自我在大同大學「數位創作與整合」課的分組專題原型：先和 AI 把想法整理成規格，再用 Claude Code 照規格一張一張任務卡實作。

## 規格書

### 一、基本資訊

- **給誰用**：為了畫角色而來，但基礎課作業總是拖到最後一晚的設計系新生。
- **一句話**：作業拆成 10 分鐘的委託，每過一關點亮 OC 設定卡的一片；交件時，作業成果變成 OC 的一部分。
- **檔案**：單一 HTML 檔（`index.html`），CSS 和 JavaScript 都寫在裡面。小人圖片放在同一層的 `sprites/` 資料夾，用相對路徑讀取。不需要伺服器，放上 GitHub Pages 就能用手機或電腦打開。
- **技術**：3D 大廳用 Three.js，小人用 PixiJS，兩個共用同一個 WebGL 畫面。兩個函式庫都打包在 `index.html` 裡，不從外部網址載入。
- **裝置**：手機直式（375×812）優先，桌機也能用。
- **資料**：不用帳號、不用登入。OC、委託進度和作業照片只存在自己的瀏覽器（IndexedDB），不會上傳。

### 二、畫面與流程

1. **建立 OC**：第一次打開會跳出卡片。輸入名字（最多 12 字）→ 從 10 隻 AI 小人選一隻，或上傳自己的圖（PNG／JPG，白底會自動去背）→ 按「進大廳」。三步完成。
2. **公會大廳**：3D 廣場。自己的 OC 腳下有粉紅光圈，鏡頭跟著它；點地板讓它走過去，WASD／方向鍵也能走；拖曳轉鏡頭，雙指或滾輪縮放。另外 6 隻小人是「公會成員」，會自己閒逛、互相打招呼，點它會跳一下、冒出一句話。右上角有「全員打招呼」「切換黃昏」。
3. **接委託**：按「委託板」→「接新委託」→ 選課程（字體設計／色彩學／平面構成／手繪基礎）→ 輸入作業名稱和截止時間 → 自動拆成 5 個 10 分鐘關卡＋1 個交件關。關卡可以改名、刪除、調整順序。
4. **開工 10 分鐘**：委託卡上按「開工 10 分鐘」→ 全螢幕大字倒數，可以暫停、提前完成、再 5 分鐘。大廳裡的 OC 走到委託板前工作。
5. **過關**：時間到會問「這一關完成了嗎？」→ 按「完成」→ OC 設定卡亮起一片，OC 跳一下說「完成一關！」。
6. **交件**：最後一關拍照或選作業照片 → 依課程變成 OC 的一部分（色彩學：從照片抽 5 個主色當配色；字體設計：名牌；平面構成：設定圖版面；手繪基礎：草稿）→ 照片放上大廳的展台，公會等級＋1。
7. **OC 設定卡**：4 區（4 門課）× 每區 3 格；一格是一張委託，切成 5 片。點任何一片，看得到是哪一天、哪張委託的哪一關。

### 三、規則

- 一關 10 分鐘；一張委託 5 關＋交件。完成一關剛好亮一片，同一關不會亮兩次。
- 倒數用開始的時間點計算：重新整理或關掉分頁再回來，剩下的時間還是對的。
- 過了截止時間的委託顯示「已逾期」，不會被刪掉。
- 公會等級＝1＋已交件的委託數。
- 照片長邊縮到 1024px 再存。
- 不做帳號、排行榜、設定頁；網頁裡不呼叫任何 AI 服務（小人圖是事先用 ComfyUI 生成好的）。

## 怎麼從組專案打包成單一 index.html

組專案是 Vite＋TypeScript 的多檔專案。`tools/` 裡的腳本把它整理成這份作業要的格式，組專案本身的檔案不用改：

1. 取組專案某個 commit 的原始碼，執行 `npm ci`。
2. `tools/build-hw5.sh <原始碼資料夾> <輸出資料夾>`：先跑型別檢查和單元測試 → 用 `tools/vite.hw5.config.mjs` 把程式打成一個 JS → `tools/inline.mjs` 把 JS、CSS 塞進 `index.html` → 圖片留在 `sprites/`。
3. `tools/check.mjs <網址> <截圖資料夾>`：用無頭 Chromium 以 375×812 實際走一次「建立 OC → 進大廳 → 重新整理」，並檢查有沒有錯誤或對外的網路請求。
